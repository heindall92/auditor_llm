Tu espacio de auditoría, protegido.

Esta dirección de GitHub Pages es la portada pública. Para ejecutar auditorías, abre la aplicación alojada en Render. El acceso pedirá usuario y contraseña. El plan gratuito usa almacenamiento efímero: exporta tus evidencias.

  1. Abre la aplicación desde el botón superior.
  2. Abre la URL del servicio y accede con el usuario auditor y la contraseña de AUDITOR_ADMIN_PASSWORD en Environment del servicio Render.
  3. Ejecuta el laboratorio. Configura un proveedor autorizado cuando quieras probar un LLM real.

La instrumentación real de agentes, MCP y aislamiento entre usuarios sigue pendiente. Las pruebas de texto no certifican la seguridad general de un modelo.
